一、程式開發與編譯（20分）

題目：指揮 AI 輸出一個能做 1 加到 N 的 Fortran 程式並完成編譯，確認可以成功執行計算並輸出結果。

答題過程（sum_n.f90 原始碼）：

program sum_to_n
    implicit none
    integer :: n, i, total

    print *, "Enter a positive integer N:"
    read *, n

    total = 0
    do i = 1, n
        total = total + i
    end do

    print *, "Sum from 1 to", n, "is:", total
end program sum_to_n

編譯與執行指令：

gfortran sum_n.f90 -o sum_n
./sum_n

三、Git 版本控制與逐行註解（20分）

題目：針對所開發的程式進行 Git 版本控制，將原版認算（commit），之後指揮 AI 針對原程式碼進行逐行註解並編譯驗證成功後，再次認算為新版。

答題過程（逐行註解版原始碼）：

program sum_to_n                  ! 定義主程式名稱為 sum_to_n
    implicit none                 ! 強制宣告所有變數的型別
    integer :: n, i, total        ! 宣告整數：n(上限), i(迴圈計數), total(總和)

    print *, "Enter a positive integer N:" ! 印出提示要求輸入
    read *, n                     ! 讀取使用者輸入的值並存入 n

    total = 0                     ! 將總和初始化為 0
    do i = 1, n                   ! 啟動迴圈，從 1 跑到 n
        total = total + i         ! 每次將 i 加進 total 中
    end do                        ! 結束迴圈

    print *, "Sum from 1 to", n, "is:", total ! 印出最終總和
end program sum_to_n              ! 結束程式

Git 操作紀錄：已完成 git init、初版 commit，以及加入註解後的第二版 commit。
